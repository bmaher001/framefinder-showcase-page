01

The accent decision

#FF0000 is the brand colour and does not change. But one hex cannot serve both a logo and an interface, so the system is a ramp built around it — same hue family, legible at 10 px.

Why #FF0000 alone fails as the UI accent

Pure red measures 4.93 : 1 on Ink 950 and 3.47 : 1 on Card. It fails AA at 10–12 px — which is exactly where timecode and confidence figures live in this product.

What the ramp does instead

The logo, the app icon and large fills stay at #FF0000, untouched. The interface draws from Signal 400 on dark and Signal 600 on light. Same brand read, legible at small sizes.

One risk, accepted knowingly

In video software red already means REC and error. A red outline on a result thumbnail reads as "recording" before "found". So red never outlines a result — the found state uses a light 1 px rule plus the bracket reticle. Red is reserved for the logo, the primary action and the playhead.

The white rule

Anything placed on a red field is white — the mark, the wordmark, UI labels, buttons, badges. Dark type is never set on red.

White on Signal 500 is 4.0 : 1 — fine for the logo and large text, not for small UI text. Where small text must sit on red, deepen the field to Signal 700 (white 9.2 : 1) rather than darkening the type.

Setting

Do

  • Sentence case for every headline and button
  • Negative tracking on display sizes only
  • Tabular figures on any number that can change
  • Arabic +1 to +2 pt against Latin at the same optical size
  • Maximum two weights per screen
  • Measure 45–70 characters

Don't

  • ALL CAPS headlines — caps belong to the meta layer only
  • Italics — the system has no italic voice
  • Letter-spacing applied to Arabic
  • Justified text in either script
  • Timecode, IDs or paths set in the sans
  • Weights below 300 or above 600

Misuse

Never stretch, condense, rotate, skew or apply perspective · add shadow, glow, outline or gradient · recolour the dot separately from the brackets · use an off-palette colour · violate clearspace · re-scale one lockup element against the other · re-set the wordmark in a live font · repeat the mark as a pattern · transliterate the name into Arabic letterforms.

Arabic lockup

The name is never transliterated into Arabic letterforms. The Latin wordmark is the mark. In RTL layouts the layout mirrors; the mark does not. Only the descriptor localises — محرّك البحث في أرشيفك.

05

Clearspace & minimum sizes

Clearspace is baked into every viewBox, measured from real ink bounds rather than the original artboard. Placing an SVG at any size preserves it automatically — no manual padding needed.

Master units: t = bracket stroke width = 28.4 · C = wordmark cap height = 106.1.

Where the wordmark is dropped

Below 32 px height the 45° terminals collapse and the counters fill in. At and below that size use the symbol only, on a solid plate. This is why Logo.tsx must branch: sm renders the symbol; md and lg render the horizontal lockup. The current component renders the full lockup at all three — at 24 px that is illegible.

Known artwork issue

The supplied vector sits ~2 units off a true t grid on the inner bracket (measured 3.07t / 4.07t where the system calls for 3.0t / 4.0t). Invisible at display sizes; visible at 7 mm print and 20 px screen. Re-draw to exact multiples before the next vector release.

Two deliberate demotions

Amber and orange map to Daylight, not to a warning colour. Amber beside red reads as a second accent competing with the brand. Warnings are carried by copy and iconography, not by a third hue.

Radius values are unchanged — 8 / 12 / 16 px in both repos. The brand does not fight the platform.
